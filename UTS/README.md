# Bintani Mart - Website Minimarket

Tugas UTS Web Programming 1 (Sesi #8). Dibuat dengan HTML dan CSS saja
(tanpa JavaScript dan tanpa framework CSS).

## Struktur Folder
```
UTS_NIM_Nama/
├── index.html      (Beranda)
├── kategori.html   (Kategori, 6 kartu)
├── produk.html     (Produk, 8 kartu)
├── info.html       (Info Toko + galeri gambar)
├── kontak.html     (Formulir kontak)
├── css/
│   └── style.css   (CSS eksternal untuk semua halaman)
├── images/
│   ├── toko-depan.jpg
│   ├── toko-rak.jpg
│   └── toko-teras.jpg
└── README.md
```

## Ketentuan yang Dipenuhi
- Header, navigation bar, konten utama (`main`), dan footer di setiap halaman
- Lebih dari 5 kartu informasi/produk
- Formulir kontak (`kontak.html`)
- Semantic HTML: header, nav, main, section, article, aside, figure, figcaption, form, fieldset, footer, address
- CSS eksternal: `css/style.css`
- Box Model: `box-sizing`, margin, padding, border
- CSS Layouting: Flexbox dan CSS Grid, responsif dengan media query

## Cara Menjalankan
Buka `index.html` di browser.
